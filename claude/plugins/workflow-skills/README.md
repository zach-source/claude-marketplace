# workflow-skills

Four skills for tools that are easy to use wrong.

| Skill | Covers |
|-------|--------|
| `granted` | AWS role assumption via `--profile` + `credential_process`, not `assume` |
| `1password` | `op` CLI with desktop-app integration; why `op whoami` probes are meaningless there |
| `herdr` | Driving herdr from inside it — workspaces, panes, agents over the local socket |
| `herdr-claude-loop` | Fanning out autonomous `/loop` sessions, one worktree per task |

Skills load on demand from their description — no wiring needed.
